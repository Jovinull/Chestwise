Chestwise adds a vanilla-friendly Storage Terminal for nearby physical
inventories. Search, move, craft, locate, and restock items while they remain in
the chests and barrels you already use—no cables, power, disks, or virtual
storage.

Supports Minecraft 1.20.1, 1.21.1, and 26.3 on Fabric, Forge, and NeoForge.
Fabric requires Fabric API. The same Fabric artifact passed basic Quilt
client/server smokes on all three lines. Quilt does not require QSL or QFAPI.

This first public version is published as a beta. See the [user guide](https://github.com/Jovinull/Chestwise/blob/main/docs/user-guide.md), [compatibility notes](https://github.com/Jovinull/Chestwise/blob/main/docs/compatibility.md), and [issue tracker](https://github.com/Jovinull/Chestwise/issues).
